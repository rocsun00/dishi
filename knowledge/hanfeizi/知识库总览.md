# 韩非子知识库

本库整理传世《韩非子》五十五篇电子工作本，按源页空行分为766段。保留篇章、论辩、经说纲领、历史故事、异传及不同人物发言，不将全书每句话一律视为韩非本人口述或亲定结论。

全书附55篇导读、766段AI释义、165张思想卡和55组问答；220处卡片及问答引句逐字匹配关联原段。独立审阅与检索试用的实际范围另见本批验收记录，不以这些规模数字代表解释准确率。

正式检索以[统一目录](../catalog.json)的 `ready` 状态为准。阅读入口：

- [原文与释义对照](阅览.html)
- [五十五篇原文](原文.md)
- [逐篇导读与逐段释义](逐篇导读.md)
- [思想索引](思想索引.md)
- [问答示例](问答示例.md)
- [底本与质量说明](质量说明.md)
- [全库总览](../知识库总览.md)

帝师可用本书检查标准与执行、权责与信息、激励与实际行为、名实核验、权力依赖、游说风险及制度的副作用。法、术、势都有古代君主控制的背景，不能把原文直接改称现代法治、平等治理或普通员工管理规则。

从本书目录执行：

```bash
python3 ../kb.py search '名实 责任' --book hanfeizi
python3 ../kb.py search '法 术 势' --book hanfeizi
python3 ../kb.py show HF-02-003
python3 ../kb.py show HF-43-001
python3 ../kb.py validate --book hanfeizi
```

每条结果显示书名、原篇号、项目段序、原文、释义提示与固定来源。检索属于词法匹配，分数不是置信度，长问题可先换为具体关键词或原句；找到一则故事后仍须阅读前后论证，不用最先命中的一句替整篇发言。

《存韩》包含李斯反驳与致韩王书；《储说》保留先经后说及重复编号的层次；《解老》《喻老》中的引经和解释是本书正文，不能误删为网站古注，也不自动等于《老子》本人主张。现代判断仍依赖用户的目标、事实、制度约束和当事人的权利。

固定版本、原始快照与提取区间保存在 `source/`，结构化正文、释义、思想卡和问答在 `data/`。本期未进行模型微调训练。
