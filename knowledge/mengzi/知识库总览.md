# 孟子知识库

本库整理传世《孟子》七篇，各分上下，共十四卷电子工作本。按所选固定电子页的卷内章句标记，保存260个完整问答或语录单元；长篇连续问答不按每个“曰”拆散。项目卷号1—14与七篇上下的对应关系保存在 `data/chapters.json` 和原段的 `part`、`source_section` 字段。

全书附14卷导读、260条逐章句AI释义、42张思想卡和14组问答。56处卡片及问答引句逐字匹配所列关联原段；这一检查证明定位与引句一致，不代表所有解释已经得到专家认可。独立复核和实际调用的范围见[本批验收记录](../验收记录-孟子荀子.md)。

正式检索以[统一目录](../catalog.json)的 `ready` 状态为准。阅读入口：

- [原文与释义对照](阅览.html)
- [七篇十四卷原文](原文.md)
- [逐卷导读与章句释义](逐篇导读.md)
- [思想索引](思想索引.md)

- [全库总览](../知识库总览.md)

帝师可借本书分析仁义与利益的先后、善意如何落实为可执行制度、稳定生计与行为的关系、局部关怀如何推扩、任贤察实、受谏改过、权衡与执一，以及穷达中如何守义。孟子不是把仁义包装为更高明的功利；他与墨家、告子、许行等存在真实分歧，引用反驳时须辨发言者，也不能将后世荀子或王阳明的系统直接放回孟子名下。

从本书目录执行：

```bash
python3 ../kb.py search '仁心 制度 执行' --book mengzi
python3 ../kb.py search '性善 四端 环境' --book mengzi
python3 ../kb.py search '权衡 执中' --book mengzi
python3 ../kb.py show MJ-07-001
python3 ../kb.py show MJ-11-008
python3 ../kb.py show MJ-13-035
python3 ../kb.py validate --book mengzi
```

检索为词法匹配，分数不代表解释置信度；长问题可拆成具体概念或原句。`MJ-13-035` 指《尽心上》第35个所选源章句，具体卷名、源章句号和固定来源随结果显示。读到名句应连同整章论辩与前后关系核对，不把卡片的现代类比当作孟子原说。

“性善”与“四端”是本书伦理人性论，不是已经完成现代实验验证的普遍定理；“民为贵”不自动等于现代民主制度；“仁者无敌”不保证现实战争必胜；“生于忧患”也不授权人为制造苦难。舜窃负父逃的设问保留亲亲与司法的张力，未强行美化为没有冲突的公私分明。相关边界分别写在释义、卡片及质量说明中。

原始固定页、来源摘要和提取记录在 `source/`，结构化原文、释义、卡片与问答在 `data/`。本库是可追溯的电子工作本和辅助阅读材料，非逐字全译、专业校勘定本；本期没有进行模型微调训练。
