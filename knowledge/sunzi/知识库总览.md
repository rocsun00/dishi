# 孙子兵法知识库

这是“帝师”的首部公开原典知识库，以《孙子兵法》传世十三篇为整理范围。它提供完整原文、逐段释义提要、逐篇论证结构、思想卡和可查证的应用示例。知识库已经具备本地检索和引用入口；它尚未进行模型微调训练。

帝师的其他已入库典籍及统一检索入口见 [全部原典总览](../知识库总览.md)。本页只说明《孙子兵法》单书范围。

优先打开 [原文与释义对照阅览](阅览.html)，从目录选择熟悉的一篇，检查解释是否忠于原文。想看“帝师”如何回答现实问题，可以先读 [问答示例](问答示例.md)。

## 这部书怎样进入帝师

问到竞争、筹划、组织、资源、风险、情报与进退等问题时，帝师可以先检索本库，找到相关段落，再结合用户的事实作判断。回答应分清本库原文、AI 的释义和面向今天的推论；重要引文给出段落编号与篇名。

例如，面对“团队效率差，是否应该重罚”，可以查《行军》的亲附与平日号令，结合《兵势》的组织条件，而不把一句兵家格言变成普遍管理处方。

本目录只覆盖《孙子兵法》。涉及其他典籍时，按统一目录确认已有的材料范围；未入库原典、范蠡史料、诸葛亮或王阳明文献，须另行取得，不能由孙子材料推定它们已具备全文依据。

## 本地检索

本工具使用 Python 标准库，无需额外安装依赖，不联网、不上传材料。以下命令从本目录执行：

```bash
python3 kb.py search '组织 协作'
python3 kb.py search '知彼知己' --limit 3
python3 kb.py show SZ-12-003
python3 kb.py validate
```

检索同时查看繁体原文、单独生成的简体检索辅助文本、简体释义和思想卡关键词，属于词法匹配，不是向量语义检索。显示与引用仍以繁体正文为准。匹配分表示检索排序，不是事实可信度；没有结果也不能证明原典没有相关思想。可换用具体关键词，或按篇名、段落编号阅读。长句提问宜先提炼成关键词。

## 可继续利用的数据

- `source/wikisource.wikitext`：未经改写的源页面文本快照，包含未入正文的网页附录。
- `source/source.json`：修订号、访问日期、原始摘要、规范化规则和范围说明。
- `data/passages.jsonl`：74 个原文段落及来源、原行号和底本异文。
- `data/search_text.json`：74 段对应的简体检索辅助文本，转换方式与摘要记录在 `source/search_normalization.json`。
- `data/analysis.json`：逐篇导读、74 段释义和39张思想卡。
- `data/examples.json`：18 个带原文定位的问答示例。
- `data/validation.json`：结构与引句的程序校验记录。

后续可将这些记录接入其他检索系统。当前版本优先保证原文与解释可分离、定位可复查；是否进一步微调模型，应由实际问题中的错误类型与评测决定。
