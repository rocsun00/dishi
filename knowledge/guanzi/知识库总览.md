## 先辨文本层次

《管子》涵盖法政、君臣、生产、心术、内业、农事、地理及轻重财政等内容，不宜把全书压成一种思想，也不把所有人物发言、转述故事、经与解均归管仲亲言。按原篇号与篇名阅读；卷号和篇内分节只是辅助结构。本文中《心术上》及数篇“解”的解释层属于选定正文，不误删作后世古注。

| 阅读方向 | 可先读篇目 | 必须辨明的边界 |
| --- | --- | --- |
| 生产与治理条件 | 牧民、权脩、乘马、治国、入国 | 民生、役使、刑罚与等级可能并存，不能只留温和语句 |
| 法令与分职 | 立政、法法、君臣上下、任法、明法、明法解 | 君主权力与严格服从的原语境，不直接等于现代法治或组织理论 |
| 修养与认识 | 心术上下、白心、内业、弟子职 | 静、虚、因、精气须按各篇定义；不能当医学、神经科学或心理治疗 |
| 时地与生产 | 水地、四时、五行、度地、地员 | 生产观察与神异、比德、感应和地域成见并存，证据类型分别处理 |
| 经济与财政 | 巨乘马、乘马数、国蓄、山国轨、山权数、轻重各存篇 | 财政统制、战争动员、价格和交易叙事有历史条件；不作现代政策效果证明 |
| 进谏与政治叙事 | 大匡、小匡、小称、四称、小问 | 区分劝戒故事、言说主体与可验证史事；不能凭典故直接识人定罪 |

《侈靡》的消费用工论述与役民控制同存；《水地》以水质论民性含地域偏见；《封禅》有传本补配性质。难句与字形占位保留，不为理论整齐补成确定原文。

## 查阅

从帝师Skill目录运行：

```bash
python3 knowledge/kb.py search '民生 分职' --book guanzi
python3 knowledge/kb.py search '轻重 蓄积' --book guanzi
python3 knowledge/kb.py show GZ-01-001
python3 knowledge/kb.py show GZ-38-003
```

`GZ-原篇号-篇内定位序号`是本项目定位方式，不冒称所有版本通用段次。索取亡篇时先查[篇目映射](source/chapter_map.json)与[缺篇表](source/lost_chapters.json)；词法近似命中不能当作该篇原文。检索分数不衡量解释正确率。

原文、源模板及来源注记分别可回查；AI释义、现代转用与边界是编纂层，不能当作古代原注。跨书使用时，轻重之“利”、心术之“虚”、君臣之“法”须逐处辨义，不能因同字便与孟荀、老庄或《商君书》强合为一说。
