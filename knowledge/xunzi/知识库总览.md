# 荀子知识库

本库整理传世《荀子》三十二篇电子工作本，保留二十卷归属，按所选固定源页的自然空行分为481个原文定位单元，共90762个字符（含标点）。这些项目段号不是所有传本通行的统一章句编号；长单元内仍可能有多组论证、人物对白或韵辞。

附32篇导读、481段AI释义、96张思想卡和32组应用辨析问答。卡片与问答共128处引句须逐字匹配关联原段；这些规模与结构检查不代表解释准确率。正式进入帝师检索以[统一目录](../catalog.json)的 `ready` 状态为准。

本书可帮助帝师辨析学习与环境、欲望与实际求取、规则与执行者、专业分工与统筹、意见偏蔽、概念名实、信用与规模、任务负荷及忠孝中的合理异议。具体建议仍须依据用户的目标、事实和当下制度，不以古典结论替代现实核验。

几个关键入口：

- `XZ-01-001`、`XZ-01-002`：善借外物、环境与持续积累。
- `XZ-12-001`：法不能自行，需要能理解并负责执行的人；不等于制度无用。
- `XZ-17-001`、`XZ-17-013`：天人之分，祈雨与雨的先后不证明因果。
- `XZ-19-015`、`XZ-23-001`：性与伪的专门定义；伪指后天修作，非虚伪。
- `XZ-21-008`、`XZ-21-012`：虚壹而静、观察条件与暂缓疑断。
- `XZ-22-008`、`XZ-22-014`：约定俗成，欲与求、判断与行动的区别。
- `XZ-29-001`、`XZ-31-006`：不盲从君父，以及不能用能力之名无限加码。

从本书目录执行：

```bash
python3 ../kb.py search '性 伪 礼义' --book xunzi
python3 ../kb.py search '偏蔽 虚壹' --book xunzi
python3 ../kb.py search '规则 执行' --book xunzi
python3 ../kb.py show XZ-23-005
python3 ../kb.py show XZ-31-006
python3 ../kb.py validate --book xunzi
```

检索为本地词法匹配，分数不是事实置信度。可换具体关键词或原句，找到结果后须看完整单元与前后论证。《性恶》不能解释成人人生来有现代意义的恶意，《天论》不能解释成现代科学已获证明或人可无限征服自然，《正名》的约定性也不是任意改词即可改事实。

《成相》《赋》保留韵辞、隐语设问与讽喻；《宥坐》《子道》《法行》《哀公》《尧问》保留不同发言者。《尧问》末段以第三人称赞孙卿，不能冒称孙卿亲口自证。《成相》赞让贤、《正论》反禅让等差异分别呈现，不为强求统一而改文。

《议兵》`XZ-15-025`保留所选电子页4个“×”占位；这不证明古籍确缺4字，另一固定四库电子本此处无相同占位。原文不静默补改，见[对读校记](对读校记.md)。《大略》若干孤条及难字采取有限释义，不拟造唯一专家定解。

逐页固定修订、原始快照、提取区间及加工记录保存在 `source/`；结构化原文、AI释义、思想卡和问答在 `data/`。审阅与实际调用的范围见[本批验收记录](../验收记录-孟子荀子.md)。本库为可追溯电子工作本，未做模型微调训练。
