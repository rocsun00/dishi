## 如何使用

先按问题找少数相关篇，再核对原段。组织分工可查《审分》《君守》《勿躬》《分职》，信息与判断可查《去尤》《察今》《察传》《疑似》，公私与任贤可查《贵公》《去私》《察贤》，生产条件可查《上农》《任地》《辩土》《审时》。这只是查阅入口，不能以书名或篇名代替论证。

```bash
python3 knowledge/kb.py search '分工 任用' --book lvshichunqiu
python3 knowledge/kb.py search '传闻 核查' --book lvshichunqiu
python3 knowledge/kb.py show LSCQ-84-001
python3 knowledge/kb.py show LSCQ-136-001
```

上面从帝师Skill目录运行。LSCQ后的数字是本项目连续子篇号；完整对应见[篇卷映射](source/chapter_map.json)。词法命中需读原段与释义，无结果应换词或查篇目。

## 读这部书时保留的区别

这是合编著作，贯通诸家不意味着内部没有张力。主张、人物对白、故事和编者评价分别阅读，不把每一句归为吕不韦亲口发言；“察今”也不能自动化解“贵公”、君臣权位与各篇时令秩序的价值冲突。现代整合由帝师按用户事实和军师守则裁决，并说明转用条件。

月令、灾异、五德终始及传统养生作为古代知识体系阅读；时机与条件的启发不能变成以古代宇宙图式预测现实。来源前两卷转向注本，325条古注已另存；内嵌括号校改保持原貌。完整来源、版本差异、程序校验与AI复核的实际范围见[质量说明](质量说明.md)及[本批验收记录](../验收记录-吕氏春秋淮南子.md)。
