# 《鬼谷子》对读校记

以下为固定电子工作本、随本古注及编纂文献之间的有限对读，不是已完成影印原刻逐字校勘。来源原貌均保留；疑点是阅读风险，不等于已经判定错字。

| 定位 | 原貌或疑点 | 处理 |
| --- | --- | --- |
| GGZ-03-001 | 貨結以采色 | 电子正文作货结，段内古注作结以采色，不私改作或结。 |
| GGZ-03-003 | 治名入産業；因危與之 | 字句难顺，进退层次可述而逐字唯一解保留。 |
| GGZ-04-001 | 罅者，𡼏也 | 来源罕字、字形保留，现代释义只述缝隙而不造罕字新义。 |
| GGZ-06-002 | 材能知𥈠 | 来源以𥈠表示智慧相关字形，显示保留；不因字形差异漏段。 |
| GGZ-07-003 | 人莫能先先事而生；可以生事美 | 电子字句及断读疑点，宽述难预先取情及利害机势，不强作逐字全译。 |
| GGZ-08-002 | 有以𠔳；𠔳者，潔也 | 来源罕字，古注从廉释洁；保留正文，不以私改凑常见廉字。 |
| GGZ-08-003 | 有不相應者；有不聽者；夫幾者不晚成，而不拘久而化成 | 断读、句义存在解释余地，不据末句给出现代固定成功时限。 |
| GGZ-09-001 | 㔻言者，決而干勇 | 罕字与分类定义不强作唯一训释，不补为流行版本其他字。 |
| GGZ-09-003 | 辭言五，曰病，曰怨，曰憂，曰怒，曰喜；恐者 | 列怨而解释恐，源列目与释项不一致，保留不校改。 |
| GGZ-10-001 | 三儀；奇不知其所壅；同惡 | 具体所指和句义有解释余地，不造固定三维模型。 |
| GGZ-10-004 | 亡不可以爲存，而危不可以爲安 | 按固定本照存，与若干流行文本的顺口措辞不得混合引用；不凭这句宣称绝不能转危为安。 |
| GGZ-10-005 | 見不可，擇事而爲之；穀逺近之誘 | 源句难顺，宽述择事与隐秘，不据疑字确定精确论断。 |
| GGZ-11-001 | 終無惑偏有利焉；陽勵於一言，隂勵於二言 | 开篇及一言二言字句不立唯一解释，不编成决策算法。 |
| GGZ-12-001 | 其被節先肉；善與而不靜 | 古注亦存先肉/无不肉异文解释，释义据上下文宽述安静居位，不改正文。 |
| GGZ-12-002 | 家于其無常也 | 源字句难定，保留在察内外开闭的上下文中，不据此作肯定名句。 |
| GGZ-13-002 | 化有五氣者，志也，思也，神也，德也。神其一長也。 | 五气列项不整齐，不补写所谓第五气，古修养论不作生理事实。 |
| GGZ-14-001 | 欲不徨；欲不偟 | 同节相邻不同字形照存，不以简体检索层倒改。 |
| GGZ-15-001 | 識氣寄，姦邪而倚之，詐謀而惑之 | 断读与语义较难，只提示意虑、候听与失实的框架，不声称唯一确译。 |
| GGZ-17-001 | 無間則不散勢者；勢敗者 | 古注对势字、败/散均有疑说，存原貌不据疑句推出确定规律。 |
| GGZ-18-001 | 轉圓 | 段内古注“疑即转丸”仅为古人意见，不宣称已补回卷中所标亡篇。 |
| GGZ-20-001 | 持樞存文 | 全节75显示字；古注疑篇简脱烂，只称现存全部而不称古本原貌完整无缺。 |
| GGZ-21-002 | 謂爻爲之生。也。 | 正文出现断裂标点，古注生另校主；照存，不据此定相貌占验之义。 |
| GGZ-21-003 | 執仇；解仇 | 本段执、篇前解及古注校解并存，标明层次而不悄改。 |
| GGZ-21-004 | 驗去亂其前；吾歸誠於己 | 句义依古注宽述，保留不定训；摄心语境含恐惧、系心，不能仅释成善意共情。 |

卷中亡篇声明原作“转丸、胠乱二篇皆亡”；同处古注言乱当篋，秦序及篇目考多作胠篋。段后古注还保存以庄子胠箧充次第及“或曰”本经中经即亡篇等不同意见。本库仅存此证据，不把被古注讨论的候选文本重新命名为完整亡篇。

古序和篇目考保存鬼谷、苏秦归属的不同意见，三家跋亦不一致。秦序以未见汉志、隋唐始著录说明流传疑点，不能据其中“近是”等评语认定确切年代；周广业以避唐讳等力主尹注，阮元仍题陶注，本库不作两说的最终裁定。
