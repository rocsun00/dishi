# 老子知识库

本库完整收录《老子》王弼本所载八十一章正文，以中文维基文库固定电子快照为工作底本。每章一段、每段有释义提要，共 81 张思想卡和 18 个问答示例。它为帝师提供可定位的原典依据，没有进行模型微调或继续预训练。

先打开 [原文与释义对照阅览](阅览.html)，任选一章，比较繁体原文、AI 释义、难点提示及现代类比。全库其他书目和统一检索见 [全部原典总览](../知识库总览.md)。

## 帝师怎样使用这部书

面对干预过多、欲望与扩张、谦下与领导、名实、责任及进退等问题，帝师先按问题检索，阅读相关章全文和解释，再判断可否类比到用户的处境。引文给出章号和段号；古代政治主张、AI 释义、现代建议分别说明。

例如，“团队执行差，该不该少管”可查第五十七章对繁禁多令的反效果批评，也查第六十六章处上不重民的要求。现代建议仍要依据实际任务、资源与表现，不能把“无为”当作无需管理、无需保护成员或无需处理责任的理由。

本库承认《老子》存在强烈的复古、抑欲、抑智、统治和宇宙论取向。将其应用于今天时，既不掩饰原意，也不把古代权力关系直接变成现实行为许可。

## 本地检索

以下命令从本书目录执行，使用统一引擎：

```bash
python3 ../kb.py search '知足' --book laozi
python3 ../kb.py search '无为 责任' --book laozi --limit 5
python3 ../kb.py show LZ-65-001
python3 ../kb.py validate --book laozi
```

检索是词法匹配，不是向量语义检索，也不自动生成结论。它同时利用原文、简体检索辅助文本、释义与思想卡；显示和引用以原始繁体正文为准。排序分数不代表真伪置信度，没有匹配也不等于原典没有相关思想。问题较长时可先提炼关键词，或直接依章号阅读。

## 资料结构与范围

- `source/source.wikitext`：固定页面的原始快照，包括未作为正文入库的王弼古注及跋、音义。
- `source/source.json`：固定修订号、时间、来源摘要、范围与加工说明。
- `data/passages.jsonl`：81 章、81 段正文，包含原行号、定位及排除古注的记录。
- `data/chapters.json`：章节与段号对应。
- `data/analysis.json`：81 章导读、81 段释义和 81 张思想卡。
- `data/examples.json`：18 个含准确原句与段号的问答。
- `data/search_text.json`：供简体词匹配的派生文本；不是另一校订本，不能替代原文引用。
- `data/validation.json`：构建时产生的结构与引句校验记录。

王弼古注保存在源快照和排除记录中，未整理为可检索的古注全文知识库。AI 释义不能冒充王弼原注。本书也未建立帛书、郭店简、河上公本等传本的系统对读；如需做版本比较，应另取对应全文及可靠校勘资料。
