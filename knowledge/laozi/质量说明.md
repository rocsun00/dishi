## 正文、古注与后附材料的区分

页面同时收有《老子》正文、王弼古注及后附跋、音义。此次将被注释分隔的正文按章合并，81 章各成一段；王弼注及跋、音义不混入正文。古注仍保留在完整快照中，已识别的注释另见段落 `editorial_notes`，但这不等于古注已按本库标准完成释读、检索与验收。

显示正文保留源字与源标点，移除折行空白、注释行冒号等格式因素；维基链接取显示文字，一作类模板保留首项并记录异文，简繁转换保护符按加工规则移除。没有以其他传本静默改写王弼本正文。简体检索文本单独保存，只用于匹配，引用回到繁体工作本。

## 解释的层次

81 段释义均为 AI 原创提要，每段约 85—106 字，不是逐字全译，不是王弼原注，也没有获得专家准确率认证。每章思想卡分别说明原语境、AI 理解、适用条件、常见误读、现代应用与边界。现代管理、生活和经营例子都是类比，需要另核用户事实，不能声称古人直接规定了今天的制度。

若干需要保留的难点如下：

| 章节 | 本库处理 |
| --- | --- |
| 第一章 | 采用工作本无名、有名及无欲、有欲的句读，注明不同断句和“此两者”指称之争 |
| 第三、十九、六十五章 | 保留使民无知无欲、绝弃圣智仁义、以愚治民的政治张力；不全部改写成反对假知识，也不据以剥夺现代教育和知情 |
| 第五章 | 说明刍狗意象及不偏私等读法，不把“不仁”一概译成仁慈，也不当作现实暴虐许可 |
| 第十、五十一章 | 以生成长养而不占有说明玄德，难句与后世养生阐释分开 |
| 第十三、十五、三十九章 | 对贵身、末句异文、数舆无舆等争议保留提示，不强定唯一结论 |
| 第二十五章 | 自然按“自己如此、自然而然”解释，不混同现代自然界或将事实直接等同正当 |
| 第三十至三十一章 | 保留战争的荒芜、伤亡、丧礼和不得已，不泛化为无代价的竞争术 |

| 第四十七章 | 如实承认不出户而知的认识主张与现代经验研究有张力，不把它改写成原文已要求数据调查 |

柔弱、不争、曲全、报怨以德都不能自动转成要求受害者继续忍耐的指令。反、祸福、天网、道生一等也不能冒充现代科学模型、因果报应保证或投资预测。

## 已做的检验及其限度

本书内容自检及共用引擎校验已通过：81 章、81 段原文、81 段对应释义、81 张思想卡、18 个问答。81 处思想卡引句加 29 处问答引句，共 110 处，均为所列对应原文的连续字符串；思想卡引句均不超过 30 个字符。章节覆盖、编号引用及 JSON 结构也已核对。

程序检验能发现漏章、错引、字符串改动等问题，不能证明释义没有哲学争议或所有现代建议有效。本期尚未与影印纸本逐字校勘，未建帛书、郭店简等系统异文表，未声称确定老子各章的唯一原貌、年代与作者。古注、版本比较及解释还应由后续专家与可靠材料继续审定。

本库离线检索不等于模型已记住全部原文。本期没有微调或继续预训练模型，也没有以程序通过率冒称决策准确率。
