# 来源处理与重建

source.wikitext由pages/01—05.wikitext完整UTF-8内容依卷序直接拼接，不注入换行或分隔符。五页Unicode字符长度依次3321、2548、1726、1482、2472，总11549；source_pages给各页连续[start,end)及独立SHA，页面原貌与两次官方API内容相等。API原响应格式不重排，批量原响应还含其他书及missing负证，不能把批量分解冒称多次网络请求。

每卷依据行首SK anchor识别子篇，跳过卷名anchor；卷一至四各五篇，卷五四篇。24子篇实际各有一行正文长自然段，完整保留24段，不按现代句读、熟句或论点切碎，不截断问答。首篇梁惠王问、尉缭子答及引述故事均在同一原自然段，speaker_context标明层次。source_markup取整条正文去源缩进后的连续切片；原行首全角缩进归excluded，正文文字一个不省。

每段source_start/end是拼接原貌的Python Unicode字符零起左闭右开偏移；source_line一基，source_page_line另给原页行号。不是UTF-8字节偏移。extraction.json将全部11549字符以passage/excluded连续无隙无重叠覆盖；排除范围仅含校对提示、页头页尾、卷与篇题、作者元数据、排版闭合和空白，不删任何论说、刑杀、连坐或武器名。chapter_map给每篇完整范围、原页、修订、首末文句、选中跨度SHA与全部段号。

主文使用全库wiki-body-v1：移除空白及支持的排版标记，不补标点、不换通行字、不更正疑字。四处SKchar索引3951、1841、195、2982原样留在source_markup，显示明确为〔四库字形:编号〕，extract_notes记录source_glyph_unencoded，不伪造汉字；古注数仍0。这些是字形未编码层，不是古注、校案或AI猜字。9255是含多字符占位的显示字符数，不能称原刻字数。

OpenCC Python reimplementation0.1.7的t2s只生成data/search_text.json，逐段一一对应；原文显示、来源及引句仍沿固定主文。清代提要、古目录、项目校记及AI解释各自分层；四库SK notes和提要只在参考原貌，不混入主文。作者自检复算切片、原API、SHA与引句，但不冒称独立来源复核或内容验收。
