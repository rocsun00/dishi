# 庄子知识库

本库完整整理传世《庄子》三十三篇，以中文维基文库逐篇固定修订快照为电子工作底本。原文按源页面自然段分为 289 段，保留内篇七篇、外篇十五篇、杂篇十一篇的区别；这是传本文献分组，不等于已经确定每篇每段的作者与年代。

全书附 33 篇导读、289 段 AI 释义、99 张思想卡和 33 个问答，132 处卡片及问答引句逐字对应所列原段。正式检索是否启用，以 [统一目录](../catalog.json) 的 `ready` 状态为准。以下文件提供完整阅读入口：

从本书目录执行：

```bash
python3 ../kb.py search '成见 判断' --book zhuangzi
python3 ../kb.py search '责任 进退' --book zhuangzi
python3 ../kb.py show ZZ-01-001
python3 ../kb.py validate --book zhuangzi
```

每个结果标明书名、篇章、稳定段号和固定来源。原文记录还含 `part` 字段标出内、外、杂篇。检索是本地词法匹配，无需额外依赖，不联网、不上传资料；排序分不代表事实置信度，没有匹配也不证明原典没有相关思想。

帝师可用这部书检查成见、知识边界、技艺与条件、过度干预、生命与名利、处境中的进退。使用时先辨说话者与寓言层次，不把故事里的孔子、盗跖等当作已核实的历史发言，也不将全书的不同主张强行合一。现代应用须另据用户事实；齐物不能取消事实差异，逍遥不能自动免除责任，养生故事不能担保免伤或延寿。

原文、源异文与 AI 释义分别保存；本期没有进行模型微调，没有把郭象等古注整理成可检索的注疏全文库。
