# 墨子知识库质量说明

本库完整范围是现存五十三篇的固定电子工作正文，非复原古代七十一篇，不包括已佚正文或现代译注全文。AI释义是帮助阅读的提要，不是逐字全译、古代注家原注或专家定解。

## 底本与篇号

主正文来自中文维基文库53个《墨子》分篇页面，于2026年10月19日通过官方API取得，每页分别固定修订号、时间、完整原始文本和摘要。首篇为[《亲士》修订2637025](https://zh.wikisource.org/w/index.php?title=墨子/親士&oldid=2637025)。全部固定链接与版本见 `source/source.json`；目录页快照另存，不能用目录页一个版本号概括53页正文。

来源归属为相应页面及其贡献者，保留[站点版权说明](https://zh.wikisource.org/wiki/Wikisource:版权信息/全文)。古代作品与站点数字整理内容分别理解。源站标点、分段不等于古代作者原有句读，站点Textquality分类也不是本库测得的准确率；《杂守》源页标50%，不可由总目录的100%推成每页都已专业校勘。

传世原篇号以[《四库全书本》古目录固定658761版](https://zh.wikisource.org/w/index.php?title=墨子_(四庫全書本)&oldid=658761)作范围对照，原快照另存 `source/reference-index.wikitext`。正文并未换成四库本，也不把两种电子文本拼接成一部底本。目录条目所列53个现存号次逐项对应；古提要自身的个别号次说法不作为重排依据。

18个缺号为：22、23、24、29、30、33、34、38、51、54、55、57、59、60、64、65、66、67。前八个有录无正文的篇名在映射表注明，其他缺号不凭本次整理擅配篇名。原篇名与对照目录的异体字分别保存。`chapter_count` 为53，而 `chapter_numbers` 保留最大至71的现存号次，稳定段号如 `MZ-25-001` 由原篇号和项目段序组成。

## 来源加工

53页各有唯一一对 `onlyinclude` 标签，严格取其内部正文。页首题记、作者栏、网页导航、页尾及类别保留于原始快照，不装入正文。`source/source.wikitext` 合并保存各页全部原文，仅在页间加有说明作用的快照分隔行；`source/pages/` 保存各页独立快照，提取区间及排除原因见 `source/extraction.json`。

按源页空行分为650段、91830个字符（含标点），没有为现代解释删并重复论述。经、经说都属于正文。《经上》《经下》源页各为一大自然段，《经说上》则有91段，这种分段差异保留，不能据本库段号声称已完成逐条经说配对校勘。

保留源字、源标点和缺字方框，移除折行空白；维基链接取显示字，受支持异文模板保留主项并将异文单列。保护符仅去外壳；有多语言项时优先 `zh`，再 `zh-hant`，再 `zh-hans`。没有用流行句子静默替换难句。

六段保留缺字方框：`MZ-52-012`、`MZ-53-001`、`MZ-53-002`、`MZ-63-005`、`MZ-70-004`、`MZ-70-014`。`MZ-71-016`的源页括注“(栗)”也原样保留，不能据括注裁定古代原字。有缺字不表示整段可以不收，也不允许AI自行补出所谓原字。

简体检索辅助层由OpenCC Python reimplementation 0.1.7的t2s配置独立生成，工具、配置与摘要见 `source/search_normalization.json`。显示和引用仍取原貌正文，运行知识库无需该转换依赖，不联网或上传材料。

## 解释与应用

导读、论证分组、逐段释义和术语提示属于AI阅读辅助。思想卡分列原典语境、解释、成立条件、误读、现代类比与边界。一个段落中的引语、问难、反驳和叙述未必代表同一立场；全书成书层次不能从网页作者栏自动推出。

墨经有讹脱、难字、孤条和不同训释。释义提供可能论旨时须留疑，不把古代关于名、实、故、类、同异、光影等讨论等同现代形式逻辑或实验科学的完整理论。无法确定的字句不因需要现代应用而补造成确定结论。

兼爱与利不能直接缩成个人财务收益；尚同包含上下政治权威的安排，不能改称现代民主共识。天志与明鬼是文本中的宗教论据，不是AI已经证实天鬼存在。非攻须与守御、诛讨叙事分别理解；非乐与节葬保留其对资源和礼俗的批评，不自动成为禁止现代艺术、丧亲表达或合理生活支出的命令。

守城诸篇保留其历史工程、宗教、军政与严刑语境。现代转用只能作有条件的阅读启发，不以古书保证施工、安全、防卫效果，也不将人质、连坐、酷刑等安排包装成组织管理最佳实践。

## 校核范围

程序校核快照摘要、逐页来源绑定、完整提取区间、53个现存原篇号、650段及释义顺序、思想卡与问答引用是否逐字匹配本书原段；单书结果保存在 `data/validation.json`。这些检查能发现漏段和错引，不能证明解释没有争议。

独立AI内容复核实际全文对读650个原段及全部释义、159张思想卡、53组问答。审阅发现并修正6条释义中的问题：战损数量级、不与/不言的疑文处理、病消亡与病死的歧义、奖誉词序、长段首项主张遗漏。原文与全部212处卡片和问答引句未因修订而改写，修复后已复读确认。此结果仍不等于专家校勘或解释准确率证明。
