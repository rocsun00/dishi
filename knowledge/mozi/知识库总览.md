# 墨子知识库

本库整理《墨子》现存五十三篇电子工作底本，保留传世篇号中的缺口，按源页空行分为650段。完整指所选现存正文全部收录，不能称已经复原古代七十一篇。经、经说、论辩、言行记录与守城材料分别保留，不把全书视为墨翟亲自定稿的一种声音。

全书附53篇导读、650段AI释义、159张思想卡和53组问答；212处卡片及问答引句逐字匹配关联原段。这些数字记录收录与定位范围，不是准确率或现实决策成绩。

帝师可用本书检查用人与利益分配、兼爱与差别待遇、战争与防卫、节用与公共成本、命定论、主张如何检验、辩论与类推的限度。原文的天志、明鬼、尚同、非乐及严厉军政秩序也须如实理解，不能只留下符合现代偏好的部分。

从本书目录执行：

```bash
python3 ../kb.py search '兼爱 利害' --book mozi
python3 ../kb.py search '三表 检验' --book mozi
python3 ../kb.py show MZ-25-001
python3 ../kb.py show MZ-45-001
python3 ../kb.py validate --book mozi
```

`MZ-25-001` 是传世第二十五篇《节葬下》的项目第一段，不是重新排序后的第二十二篇。53个现存原篇号及18个缺号见 `source/chapter_map.json`，原篇号也显示于检索结果。检索为词法匹配，分数只用于排序，无结果可换具体原句或查看篇目，不表示原典没有相关讨论。

索取《节用下》等具体篇目时，先核对该映射表和质量说明。检索可能返回《节用上》《节用中》或别篇的相似词，这不能证明所求篇已存在；通用未找到提示也不能单独证明该篇佚失。确认目录缺篇后不补造所谓原文。

每个结果带原文、释义、读法提示及固定来源。处理现实问题时，分别核对公共利害与私人好恶、反对侵略与必要防卫、标准检验与单一权威；现代结论仍须现实证据。墨经难句未建立唯一训释或逐条经说校订；古代城防篇的工程数度、刑罚与人质安排也不能直接移作现代操作规则。

源页缺字方框原样保留，未补造字句。各页固定快照与加工映射保存在 `source/`，正式数据在 `data/`。这是一套可检索知识库，没有进行模型微调训练。
