# 论语知识库

本库完整整理所选电子工作本《论语》二十篇，按底本原有章句标记分为 501 个定位单元，每段均有 AI 原创释义提要；另有 20 篇导读、60 张思想卡和 24 个有原段依据的问答。它给帝师补充仁、礼、义、忠恕、修己、识人、用人与为政等材料，没有进行模型训练。

先读 [《雍也》敬简问答](阅览.html#chapter-6) 或 [《先进》因人进退](阅览.html#chapter-11)，再看 [问答示例](问答示例.md)。面对现实决策，先读原段和解释，再区分哪些是古代要求、哪些只是现代类比。

## 怎样参与实际判断

讨论“团队执行力差，该改制度还是换人”，《雍也》区分内心敬慎而办事简要与内外皆简略，能帮助检查精简是否变成草率；《尧曰》所列不教责成、慢令急期，要求同时检查发令者的责任。《先进》的因人进退则提醒，同一处方未必适合不同能力与倾向。

这些材料不能独自决定某位员工该走该留。现代判断仍需任务标准、资源权限、交付记录和当事人的说明；也不能把古代刑罚、臣属和役民关系直接移入劳动关系。

理解《论语》还须面对难处：民可使由之的句读、父子相隐的亲亲立场、女子小人的性别与身份观念，以及孔子与弟子间不同的声音。本库保留这些张力，不为了塑造完美顾问而把原典都解释成现代平等管理学。

## 本地检索

从本书目录执行：

```bash
python3 ../kb.py search '执行 教 期限' --book lunyu
python3 ../kb.py search '朋友 直 信' --book lunyu
python3 ../kb.py show LY-11-021
python3 ../kb.py validate --book lunyu
```

从帝师 Skill 目录执行时，脚本路径改为 `knowledge/kb.py`。支持繁体原文、独立简体辅助文本、释义和思想卡的词法检索。分数只表示匹配排序，不能当作解释可信度或建议成功率。引用显示原段；若属于已列疑点，应一并查看对读校记。

## 数据与边界

`source/pages/` 保存二十个分篇固定修订的原始维基文本，`source/source.wikitext` 是合并快照。`data/passages.jsonl` 记录正文、源位置、`source_section` 原网页章句标签及分离的编辑注记。501 段是本电子底本的实际分章，不强行等同其他版本的章句总数。

`data/analysis.json` 保存导读、释义与思想卡，`data/examples.json` 保存问答；`source/collation.json` 和 `source/comparison/` 保存六处有限电子对读证据。运行与引用以正式数据为准。

本书不是孔子亲写的系统专著。对话者有不同身份，后段多为弟子及后学言论，圣王引辞也不能一律标作孔子直接发言。释义是概要而非逐字全译，不等于已完成考据；公开全文、AI 解读、古注和现代应用具有不同证据地位。
