# 来源处理与重建

工作正文为pages/00.wikitext的完整UTF-8内容，逐字复制为source.wikitext；两者字节一致。页0标题/固定revid的API均保留原始响应；metadata中的SHA256按文件字节计算。参考页1、2仅作古著录与清代书目意见，页3、4仅为包含页结构，均不拼入正文。

按源中六条行首二级标题依序识别六篇；每篇正文非空行即一个源自然段，按原顺序保留完整行。主文原段均为单行，空行只分段。只排除页头header、二级篇题、空白、gototop、PD-old及Category分类，不排除任何正文论说、问答、战果叙述或暴力语句。六篇取10、5、8、5、10、5段。完整源从0至len(raw)=6343的每一个Python Unicode字符均归passage或有理由的excluded，连续区间无缺口重叠。

每段source_markup严格等于source.wikitext[source_start:source_end]，text由全库既有wiki-body-v1 normalize_markup生成；原文汉字、标点不猜改。source_line为起点前换行数加1。每段保留source_natural_paragraph，首两处跨空行问答共享source_dialogue_group。主文无段内古注模板，extract_notes结果全为空；这不是古注已完成校勘的声明。

chapter_map记录各篇固定来源、正文首尾偏移、首尾文句、段号及选中跨度SHA。extraction.json是穷尽提取清单，source.json记录本书与页面身份。API核验从query.pages唯一页读revisions[0]，校对title、revid、UTC版本时间与slots.main.*；标题请求与revid请求内容必须相同，API文件不得重排或美化以替换原响应。

OpenCC Python reimplementation 0.1.7的t2s仅用于data/search_text.json，逐段与原段号一一对应；显示与引句仍读passages的原字。完整现代释义、卡、问答与程序生成展示分开，原典、古书目见解、现代解释不混为一层。

rightsinfo由同批司马法采集共享，原响应、其采集UTC/URL/SHA与共享路径均在fetch_manifest中。原响应的采集落盘时间由保存API的文件时间重建；上游修订UTC另列，二者不混用。来源归属及许可细节见书级来源与许可.md。
